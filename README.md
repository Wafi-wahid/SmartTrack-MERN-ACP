# SmartTrack-Track Your Work

## Description:
Developed SmartTrack, a full-stack productivity and personal management application that helps users organize daily tasks, manage schedules, maintain journals, and build healthier habits. The platform combines task management, calendar planning, productivity analytics, and wellness features into a single dashboard to improve time management and personal efficiency.

## Key Contributions
• Built a secure MERN stack application with user authentication and personalized dashboards.<br/>
• Implemented complete CRUD functionality for task and journal management.<br/>
• Integrated a calendar system for scheduling events, deadlines, and task timelines.<br/>
• Developed interactive analytics dashboards to visualize task completion, productivity trends, and journal activity.<br/>
• Created a digital journaling feature for tracking daily reflections and personal progress.<br/>
• Added wellness features including guided meditation and habit-focused productivity tracking.<br/>
• Designed a responsive and intuitive user interface with reusable React components.<br/>

## Technologies

React.js • Node.js • Express.js • MongoDB • JavaScript • JWT Authentication • Calendar API • Chart.js/Recharts • REST APIs • Tailwind CSS • Git • GitHub
